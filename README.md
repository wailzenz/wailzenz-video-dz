# wailzenz-video-dz 🇩🇿

**مونتاج فيديوهات بالدارجة الجزائرية مع Claude Code — مجاناً وعلى جهازك.**

صوّر روحك تهدر للكاميرا، أعطِ الفيديو لـ Claude، وخذ ريل 9:16 واجد للنشر على Instagram وTikTok وYouTube Shorts:
ينحّي السكتات والغلطات، يكتب كابشن عربي كلمة بكلمة، يزيد موشن قرافيك ومؤثرات صوتية، ويدير الغلاف.

[English](README.en.md) · [Français](README.fr.md)

![كابشن بالدارجة مع ترجمة الكلمات الفرنسية والإنجليزية](docs/img/captions-gloss.png)

## واش يدير؟

| | |
|---|---|
| ✂️ **القص بالعقل** | ينحّي السكتات الطويلة برك، ما يقطعش وسط كلمة، والجملة المعاودة يخلّي المحاولة الثانية |
| 🗣️ **التفريغ بالدارجة** | Whisper large-v3 على كرت الماك، ولا موديل جزائري مدرّب على الدارجة (Hadra) — تختار الأحسن لصوتك |
| 💬 **كابشن عربي كلمة بكلمة** | الحروف متصلة، الاتجاه من اليمين لليسار، والكلمة اللي راك تقولها تتلوّن |
| 🇫🇷🇬🇧 **الكلمات الفرنسية والإنجليزية** | تبقى بالحروف اللاتينية ومن بعدها ترجمة عربية بين "" ← «هادي حاجة normal "عادية"» |
| 🪝 **الهوك المكتوب** | جملة قوية في أول ثانيتين، مراقبة باش تكون بالدارجة الجزائرية (ماشي «شلون» و«وايد») |
| 🎬 **موشن قرافيك** | 100 حركة جاهزة، كلام يفوت وراء راسك، خرائط، أرقام، بطاقات… |
| 🔀 **شاشة مقسومة تتبدّل** | الرسم مرة فوق ووجهك تحت، ومرة وجهك فوق والرسم تحت — باش الفيديو ما يملّش |
| 🪟 **شريط فوق الفيديو** | ماشي ديما 50/50: شريط رقيق فوق ولا تحت، ووجهك يبقى في الشاشة كاملة — على كارت شفاف ولا مباشرة على الصورة |
| 🧠 **رسوم تشرح، ماشي كابشن ثاني** | الرسم ما يعاودش الكلام اللي في الكابشن: أيقونات، واجهات (terminal، timeline)، لوحات مقارنة |
| 🔊 **الصوت** | تنظيف الصوت، مؤثرات صوتية (whoosh، pop…) بلا حقوق، وتسوية الصوت على ‎-14 LUFS |
| 🎙️ **أكثر من الريل** | بودكاست ← ريلز، مونتاج على الإيقاع، فيديو موشن بلا تصوير، وأغلفة/Thumbnails |

كلشي يخدم **على جهازك**: الفيديو تاعك ما يطلعش للإنترنت.

## واش لازمك

- **Claude Code** (يحتاج اشتراك Claude — البلقن مجاني، Claude ماشي مجاني).
- **Mac** — والأحسن Apple Silicon (M1 ولا أحدث)، 8 GB RAM على الأقل (16 GB أريح)، و10 GB فارغين.
- **Google Chrome** (المحرّك يرسم بيه الكابشن).
- Windows وLinux: يخدم بالتفريغ العادي (`--engine whisper`)، بصح التجربة الكاملة على الماك. شوف [docs/INSTALL.md](docs/INSTALL.md).

## التنصيب

في Claude Code:

```
/plugin marketplace add wailzenz/wailzenz-video-dz
/plugin install wailzenz-video-dz@wailzenz-video-dz
```

من بعد، أول مرة برك، قول لـ Claude: **«وجّد لي الأدوات تاع wailzenz-video-dz»** — ولا شغّل بنفسك:

```bash
bash ~/.claude/plugins/marketplaces/wailzenz-video-dz/setup/setup-mac.sh
```

يحمّل حوالي 4 GB (ffmpeg، Whisper، PyTorch…) في `~/.wailzenz-video-dz`. التفاصيل في [docs/INSTALL.md](docs/INSTALL.md).

## الاستعمال

حط الفيديو في مجلد، وقول لـ Claude:

> «مونتيلي هاد الفيديو ودير منو ريل» · «نحّي السكتات ودير كابشن» · «دير لي ريلز من هاد البودكاست» · «دير لي غلاف»

Claude يسقسيك على الحوايج المهمة برك (الألوان، الشعار، واش تحب تنحّي)، ويوريك صور قبل ما يكمّل.
