# كلمة الختام ← رابط الحلقة بالخاص

كل ريل من حلقة ينتهي بنفس الدعوة: **«اكتب [كلمة] توصلك الحلقة كاملة»**. الكلمة تكون واحدة لكل حلقة (اسم البرنامج أو الحلقة)، وتتكرر بكل ريلاتها.

## كرت الختام (من الثيم)
المحرّك يرسم الكرت من `theme.json ← outro` (الافتراضي إعلان السكل نفسه — **غيّره دايماً** لريل البودكاست):

```json
"outro": {
  "l1": "من حلقة بودكاست «قبل العصر»",
  "l2": "صناعة المحتوى عبر تلفزيون الكويت",
  "cta": "اكتب",
  "word": "قبل العصر",
  "sub": "يوصلك رابط الحلقة"
}
```
الحقول: `l1` `l2` (سطرين فوق) · `chips` (اختياري) · `cta` (الدعوة) · `word` (الكلمة داخل القرص الملوّن) · `sub` (سطر تحت). الكلمة لازم تتكتب نفسها بالكابشن والكرت والأوتوميشن.

## الأوتوميشن (اختياري — المستخدم يقرر)
الريل ينفع بدون أوتوميشن (المشاهد يكتب الكلمة وانت ترد يدوياً)، بس لو كثروا فالأحسن أداة تردّ لحالها:

- **المبدأ:** أي بوست عليه الكلمة بتعليق ← رسالة خاصة فيها الرابط. أوتوميشن واحد على «أي بوست» بدل واحد لكل ريل، فكل ريلات الحلقة تشتغل عليه.
- **أدوات:** ManyChat، Zorcha، أو أي أداة ترد على التعليقات برسالة خاصة — المستعمل يختار، وما نفرضوش عليه حتى وحدة.
- **للـAI:** اذكر الأدوات **غير إذا المستعمل سقسى على الأتمتة**، وما تقول والو على الأسعار.

## قواعد
- لا تسوّي أوتوميشن ولا تشغّله بدون قول المستخدم الصريح — الرسائل تطلع بحسابه.
- افحص رابط الحلقة يفتح قبل ما تحطه برسالة.
- الرسالة بلهجة المستخدم، قصيرة، وفيها زر الرابط.
